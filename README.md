# AI Learning Portfolio

เว็บไซต์ Portfolio สรุปการเรียนรู้จากไฟล์ `AI!01.pdf`

## ไฟล์
- `index.html` — โครงสร้างเว็บไซต์
- `style.css` — ดีไซน์และ Responsive
- `script.js` — เมนูมือถือ, animation และปุ่มกลับด้านบน

## เปิดดูในเครื่อง
ดับเบิลคลิก `index.html` เพื่อเปิดใน Browser

## นำขึ้น GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลด `index.html`, `style.css`, `script.js`
3. ไปที่ Settings → Pages
4. ใน Build and deployment เลือก Source = Deploy from a branch
5. เลือก Branch = `main` และ Folder = `/ (root)`
6. กด Save
7. รอสักครู่ แล้วเปิดลิงก์ GitHub Pages ที่ GitHub แสดงให้
